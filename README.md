# 江农校园网守卫（jxau-campus-net）

江西农业大学校园网（锐捷 ePortal）的自动认证与断线自愈脚本。

开机不用再点认证页，掉线了自己连回来，会话到期前会按要求保活。

> **适用范围**：本校 SSID `JXAU`、认证服务器 `10.255.240.8` 的 ePortal 认证。
> 其他学校、其他厂商（华为 / 深澜 / Dr.COM 等）的认证本脚本不适用。

## 快速开始（图形界面）

**下载**：到本仓库右侧 [Releases](https://github.com/yi117/jxau-campus-net-v2/releases/latest) 下载 `jxau-campus-net-v*-win.zip`，解压即用。

解压后**双击 `GuardUI.exe`**，按三步走：

1. **录入 / 修改账号…** —— 填学号和密码（用 Windows DPAPI 加密存本机）
2. **安装 / 修复开机自启** —— 弹 UAC 授权，注册计划任务
3. 状态卡片变成「在线」就成功了

之后开机自动在后台跑，不用再打开这个窗口。界面上还能暂停、重启、看日志、清日志、卸载。

> 界面和脚本必须在**同一个文件夹**里。如果你想分开存，点界面里的「指定脚本目录…」，
> 选中 `guard.ps1` 所在目录即可。

不想用界面、只想要命令行？下面是原来的方式，两者用的是同一套脚本。

## 为什么需要它

学校的认证是 ePortal。认证成功后，服务器返回一个 `userIndex` 作为这条会话的编号，
会话空闲一段时间就会被认证设备踢掉。中间还有两个坑：

1. **认证设备的响应经常超时**，第一次登录拿不到 `userIndex`，会话只活两分钟；
2. **关机前的旧会话不会马上释放**，开机会被判 "Too many access"，得等它超时才能登进去。

脚本做的就是把这些事接管掉：登录、保活、掉线重连、清残留会话。

## 功能

- 开机自动登录，桌面不弹任何窗口
- 每 30 秒发一次保活（`keepalive`），防止空闲被踢
- 掉线自动重连；遇到 `Too many access` 先注销残留会话再试
- 登录响应超时也能救：按 `userIndex` 的生成规则自己拼一个，先保活接管会话
- 重连预算 5 分钟：连着试 5 分钟还不行就停手，等你手动登录，不再骚扰认证设备
- 可选：关掉 Windows "连上需要登录的网络就自动打开浏览器"
- 可选：关掉 Wi-Fi 网卡的省电断开

## 一、下载哪些文件

在仓库页右上角点 **Code → Download ZIP**，解压到**一个固定的文件夹**，比如：

```
D:\campus-net
```

> 别解压到桌面或"下载"文件夹。那两个地方经常被清理软件扫，脚本被删掉之后计划任务就空转了。

解压后应该有 **17 个文件**，必须全部放在同一层目录里（脚本之间按相对路径找对方）：

| 文件 | 必需 | 作用 |
|---|---|---|
| `install.cmd` / `install.ps1` | ✅ | 录入账号、注册计划任务 |
| `guard.ps1` | ✅ | 守护进程本体，所有逻辑都在这 |
| `launch.vbs` | ✅ | 无窗口启动守护进程（计划任务调它） |
| `uninstall.cmd` / `uninstall.ps1` | ✅ | 卸载并还原 |
| `status.cmd` / `status.ps1` | 常用 | 看状态、看日志 |
| `selftest.cmd` | 常用 | 主动注销一次，验证能不能自己登回来 |
| `tune-wifi.cmd` / `tune-wifi.ps1` | 可选 | 关掉网卡省电断开 |
| `no-portal-popup.cmd` / `.ps1` | 可选 | 关掉开机自动弹浏览器 |
| `README.md` / `LICENSE` / `.gitignore` | 不用管 | 说明和许可，脚本不读它们 |
| `使用说明.md` | 不用管 | 一页速查，详细内容就是本 README |

**两个坑：**

1. **只下 `.cmd` 是不行的**——每个 `.cmd` 都只是壳子，真正干活的是同名的 `.ps1`。
2. 如果 Windows 提示"这些文件来自其他计算机"，在文件夹里全选 → 右键 → 属性 → 勾"解除锁定"。
   （不解除多数情况也能跑，但个别杀软会拦。）

## 二、第一次使用

### 1. 安装

双击 **`install.cmd`**：

1. 提示输入"校园网账号（学号）"——就是认证页上那个用户名
2. 提示输入密码，**输两次**（输入时不显示，打错会当场提示）
3. 弹出 UAC，点"是"
4. 新窗口里会打印状态，看到 `认证：已登录 userIndex=...` 或 `判断：在线` 就成功了

密码会立刻用 Windows 的 DPAPI 加密存到本机，明文不落盘、不联网上传。

### 2. 看状态

双击 **`status.cmd`**，重点两行：

```
守护阶段：在线
认证：已登录 userIndex=6661303336...
```

- `userIndex` 有值 → 会话归它管了，掉线会自动重连
- `userIndex` 空、阶段显示"已停止自动重连" → 需要你手动打开认证页登一次

### 3. 建议顺手做两件（各一次，都要 UAC）

- **`tune-wifi.cmd`**：关掉"允许计算机关闭此设备以节约电源"，减少网卡省电导致的掉线
- **`no-portal-popup.cmd`**：关掉 Windows 开机自动拉起浏览器打开认证页

两个都可以用 `-Revert` 还原，比如 `tune-wifi.cmd -Revert`。

### 4. 验证掉线自愈（可选）

双击 **`selftest.cmd`**：它会主动注销当前会话，然后看守护进程能不能自己登回来。
中间会断网 5~10 秒，属于正常。

如果密码被服务器拒绝，这一步会让你暂时离线——用浏览器打开认证页手动登一次即可。

## 三、之后怎么用

**什么都不用做。**

装完会注册一个叫 `CampusNetGuard` 的计划任务，登录 Windows 时自动启动守护进程，桌面不弹窗口。
之后：

- 掉线 → 自己重连
- 会话快到期 → 每 30 秒发一次保活
- 关机前没释放的残留会话 → 开机会先注销再登录

只有一种情况需要你出手：**自动重连连续试了 5 分钟还没成功**，它会停手（避免把账号试锁），
这时手动打开认证页登一次，它接着接管。

重连预算的规则：

- 从这一轮第一次发现认证页开始计时，总共 5 分钟，期间按 5/15/30/60 秒退避重试
- 用完还没连上 → 停止自动重连，只探测不登录
- 之后你手动登上去，它重新接管并继续保活
- 连续稳定在线满 5 分钟，才恢复自动重连能力（避免"断了就连、连上又断"无限循环）

时长可在 `%LOCALAPPDATA%\CampusNetGuard\config.json` 里改 `reconnectWindowSec`。

## 四、它会改什么

### 系统层面

| 改动 | 说明 | 怎么还原 |
|---|---|---|
| 计划任务 `CampusNetGuard` | 登录时启动 + 每 5 分钟自检一次 | `uninstall.cmd`，或任务计划程序里禁用 |
| 目录 `%LOCALAPPDATA%\CampusNetGuard\` | 放加密凭据、配置、日志、状态 | `uninstall.cmd` |
| 网卡"允许关闭以节约电源" | 仅 `tune-wifi.cmd` 改过才有 | `tune-wifi.cmd -Revert` |
| 电源计划"无线适配器节能模式" | 仅 `tune-wifi.cmd` 改过才有 | 同上 |
| 两个 HKLM 策略键 | 仅 `no-portal-popup.cmd` 改过才有，用于禁止自动打开浏览器 | `no-portal-popup.cmd -Revert` |

除此之外**不动任何系统设置**：不装驱动、不改 hosts、不改 DNS、不动防火墙、不碰系统代理。

### 运行时的开销

- 常驻 1 个 `powershell.exe` 进程，内存 70~90 MB，CPU 接近 0
- 每 30 秒一次 HTTP 探测（约 1 KB）
- 在线时每 30 秒一次保活请求
- 日志每 30 分钟留一条"在线巡检"，文件超过 2 MB 自动轮转

### 网络行为

只访问三个地址：

- `www.msftconnecttest.com` / `connect.rom.miui.com`（探测"通不通"）
- `10.255.240.8`（学校的认证服务器）

不访问任何第三方，不上报任何数据。连到别的网络（手机热点、家里的 Wi-Fi）时它会自动静默，不会把账号发出去。

### 安全

- 密码用 Windows DPAPI 存在当前 Windows 账户下，**换个账户或重装系统就解不开**，需要重新录
- 日志里有账号名，没有密码
- 不要把 `%LOCALAPPDATA%\CampusNetGuard\credential.dat` 发给别人

## 五、常见问题

**双击 install.cmd 一闪就没了**
杀毒软件拦了，或者文件被标记为"来自网络"。右键属性解除锁定，或把整个文件夹加入杀软白名单。

**UAC 点了取消**
没装成，重新双击一次即可。

**status 显示"账号或密码被拒"**
密码不对，重新跑 `install.cmd` 录入。

**status 显示"已停止自动重连"**
5 分钟预算用完了。手动打开认证页登一次，登上去它会自动接管。

**同一账号手机也在用**
学校的并发策略可能互踢，脚本只能负责把自己的登回来。

**换了新电脑**
重新下载、重新装一遍。凭据不会跟着走。

**学校启用了验证码 / 改了认证页**
脚本会停下来写日志，不会死循环。这种情况把日志发出来一起看。

## 六、卸载

双击 **`uninstall.cmd`**：

1. 停止并删除计划任务
2. 用备份还原网卡设置（如果改过）
3. 删除 `%LOCALAPPDATA%\CampusNetGuard\`（会先问你要不要保留账号）

卸载后上网回到原始状态：自己打开认证页登录。

只关掉某一项也行：

```powershell
.\tune-wifi.cmd -Revert          # 还原网卡省电设置
.\no-portal-popup.cmd -Revert    # 还原浏览器自动弹出
```

## 工作原理

```
每 30 秒：
  GET  http://www.msftconnecttest.com/connecttest.txt
       204/200  → 在线 → 到点发 keepalive
       302      → 认证页 → 取 Location 里的 queryString → 登录
       无响应   → 门户端口也连不上 → 判定链路问题，限频重连 Wi-Fi
```

登录请求与浏览器完全一致：

```
POST http://10.255.240.8/eportal/InterFace.do?method=login
Content-Type: application/x-www-form-urlencoded

userId=<双重URL编码的账号>&password=<双重URL编码的密码>&service=
&queryString=<双重URL编码的跳转参数>&operatorPwd=&operatorUserId=
&validcode=&passwordEncrypt=false
```

返回 `{"result":"success","userIndex":"...","keepaliveInterval":"..."}`。

`userIndex` 不是随机串，是 `<nasip>_<本机IP>_<账号>` 的十六进制，例如：

```
a1b2c3d4e5f60718_192.0.2.10_2026000000
```

所以登录响应超时时，脚本能自己拼一个去发保活，先把会话接管下来。

失败分类：

| 情况 | 处理 |
|---|---|
| `Too many access` / 已在线 | 按规则拼出 userIndex，调 `logout` 注销残留会话，隔 2 秒重登 |
| 密码/账号错误 | 停止重试，日志写原文 |
| 要验证码 | 停止重试，提示手动登录 |
| 其他 | 退避重试 5/15/30/60/120 秒；10 分钟内超过 6 次暂停 10 分钟 |

开机那会儿经常撞上 `Too many access`：关机前那条会话还没从认证设备上释放。
现在会先把它注销掉再登录，不用等它自己超时。

## 安全与边界

- 账号密码用 Windows DPAPI 加密存在本机，明文不落盘，不上传任何地方
- 只把认证请求发给学校的认证服务器；换到手机热点、家用 Wi-Fi 会自动静默
- 只用**你自己的账号**，不提供共享账号、批量尝试之类的功能
- 校园网使用遵循学校网络管理规定，使用前请自行确认允许范围
- 软件按现状提供，不承诺任何效果；因使用产生的后果由使用者自负
